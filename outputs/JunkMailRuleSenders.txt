How to set this up in classic Outlook:
1. File > Manage Rules & Alerts > New Rule > "Apply rule on messages I receive" > Next.
2. Check "from people or public group", click the underlined link, and add each address above.
3. Next > check "move it to the specified folder" and pick "Junk Email" for this account.
4. Finish. Do not run the rule now on existing messages - the matching Inbox mail has
   already been moved to Trash separately.

Note: attempting to create this rule via Outlook COM automation failed with
"One or more rules cannot be saved because of invalid actions or conditions" for this
IMAP account, even for a plain Subject condition moving to a normal folder - Outlook's
rule engine appears to reject rules created this way for this store, so it must be set
up by hand in the Rules Wizard UI.
